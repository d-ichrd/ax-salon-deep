# AX 살롱 뤼미에르 · 최종본

폴더가 두 개예요.

- **vercel-site/**: Vercel에 올리는 사이트 파일이에요.
- **apps-script/**: 구글 시트에 붙이는 기록 서버 코드예요. Vercel에는 올리지 않아요.

## 1. Vercel에 올리기

지금 Vercel 프로젝트 폴더에 `vercel-site/` 안의 파일을 **덮어써서** 넣어요. 지금 있는 아래 파일과 폴더는 **지우지 말고 그대로 두세요.** 제가 가진 적이 없는 파일이라 최종본에 들어 있지 않아요.

- `assets/` 폴더 (arch.jpg, table.jpg, people/ 안의 프로필 사진들)
- `favicon.svg`
- `og.jpg` (공유 미리보기 이미지)
- `config.js` (참석 회신서 접수 주소)

올린 뒤 이렇게 열려요.

| 주소 | 페이지 |
|---|---|
| `/` | 행사 소개와 참석 회신 (최종 B안) |
| `/b.html` | 이미 공유된 B안 링크용. 자동으로 `/`로 넘어가요 |
| `/program.html` | 오늘의 순서지 (참석자 모두) |
| `/table.html` | 둥근 탁자: 카드, 촛불 타이머, 워크시트 올리기, 방명록, 투표 |
| `/dashboard.html` | 진행자 대시보드 |
| `/directory.html` | 참여자 명함첩 (참여자 열쇠 필요) |
| `/worksheet.pdf`, `/cards.pdf` | 인쇄용 워크시트, 질문 카드 15장 |

예전 A안 페이지(기존 index.html)와 비교 페이지(compare.html)는 최종본에서 뺐어요. 기존 index.html은 새 파일로 바뀌고, compare.html은 Vercel 폴더에서 지워 주세요.

## 2. 기록 서버 연결 (행사 전 한 번)

1. 새 구글 시트를 만들고 **확장 프로그램 > Apps Script**에 `apps-script/apps-script.gs`를 붙여 넣어 저장해요.
2. 함수 목록에서 `setup`을 실행하고 권한을 허용해요. 실행 로그에 나온 **진행자 열쇠, 기록자 코드, 참여자 열쇠, 사진 폴더 주소**를 메모해요.
3. AI 기능을 쓰려면 프로젝트 설정 > 스크립트 속성에 `ANTHROPIC_API_KEY`를 추가해요.
4. **배포 > 새 배포 > 웹 앱**을 골라요. 실행 사용자는 "나", 액세스 권한은 "모든 사용자"로 두고, 나온 주소(…/exec)를 복사해요.
5. 그 주소를 두 곳에 넣어요.
   - `live.config.js`의 `endpoint`: 탁자, 순서지, 대시보드, 명함첩이 연결돼요.
   - 기존 `config.js`의 `applyEndpoint`: 참석 회신이 같은 시트의 `rsvp` 탭에 쌓여요.
6. `live.config.js`의 `sheetUrl`(시트 주소), `driveUrl`(사진 폴더), `wifi`를 채우고 Vercel에 다시 올려요.

서버를 연결하기 전에는 모든 현장 페이지가 **미리보기 모드**로 돌아가요. 기록은 그 브라우저에만 남아요.

## 3. 당일 흐름

1. **입장**: 대시보드 > 현황 > "탁자 페이지 QR 띄우기"를 화면에 띄워요. 순서지 주소는 단톡방으로 보내요.
2. **16:15 탁자 토론**: 참석자가 탁자 번호를 고르고 카드를 정해요. 촛불 타이머가 4단계를 안내해요.
3. **16:40쯤 기록**: 기록자가 워크시트를 찍어 올리면 AI가 발표 메모 초안을 써요. 기록자가 고쳐서 저장해요.
4. **17:05 발표**: 대시보드 > 발표 무대에서 순서를 뽑고 ← →로 넘겨요. 스페이스를 누르면 5분 타이머가 돌아요.
5. **17:35 투표**: 대시보드 > 투표에서 열기 → 닫기 → 결과 공개 순으로 눌러요.
6. **행사 뒤**:
   - 대시보드 > 오늘의 정리에서 AI 초안을 고쳐 공개해요. "구글 문서로 기록 묶기"를 누르면 전체 기록이 문서로 묶여요.
   - 불참자는 시트 `rsvp` 탭의 `hide` 칸에 아무 글자나 적어 명함첩에서 빼요.
   - 감사 메시지에 순서지 주소와 **참여자 열쇠**를 담아, 연락처 공유에 동의한 분께만 보내요.

## 4. 행사 전에 확인할 것

- **og.jpg**: 이미지 안에 예전 부제("그래서 뭘 해결했는데?")가 글자로 들어 있다면 새로 만들어야 해요. 카카오톡 미리보기는 카카오 공유 디버거에서 캐시를 초기화해요.
- **워크시트 QR**: `ax-salon-deep.vercel.app/table.html`로 연결돼요. 주소가 바뀌면 다시 만들어야 해요.
- **AI 안내**: 워크시트 사진과 방명록 문장이 AI(Anthropic API)로 보내진다는 점을 문 열 때 한 번 알려 주세요.
- **사진 공유 정책**: 학교 구글 계정은 사진 공유가 막힐 수 있어요. 개인 계정으로 시트를 만드는 편이 안전해요.
- **리허설**: 휴대폰 두 대로 사진 올리기, 투표, 방명록을 한 번씩 해 보세요. 시험 기록은 시트에서 행을 지우면 사라져요.
